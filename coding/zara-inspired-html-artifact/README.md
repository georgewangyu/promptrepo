# Zara-Inspired HTML Artifact Layer

## Core Idea

Turn technical work into a polished static HTML artifact that feels like a
beautiful developer notebook, not a generic AI report.

This layer is adapted from Zara Zhang's public `codebase-to-course` and
`frontend-slides` pattern: use code as source material, preserve exact snippets,
and present the explanation through warm typography, visual rhythm, diagrams,
and interactive teaching blocks.

## When To Use

- repo onboarding packets
- architecture walkthroughs
- agent eval reports
- implementation retrospectives
- codebase-to-course or codebase-to-interview artifacts
- technical launch pages and proof objects

## Why It Works

Most agent output looks disposable because it is plain markdown, generic cards,
or purple-gradient AI decoration. This layer forces the agent to build an
artifact with a real design language:

- warm notebook palette instead of cold SaaS chrome
- one bold accent color
- exact code beside plain-English interpretation
- visual explanations before paragraphs
- scrollable modules with progress and rhythm
- quizzes, tooltips, diagrams, or data-flow animations when they help learning
